# 城市骑行侠 · City Rider

一个纯前端、零依赖的公路车骑行小游戏。在九座中国城市的街景里一路骑到终点：躲车、捡金币、抢检查点续时间，完赛后生成一张可以直接发出去的领奖台晒图。

单文件实现，`index.html` 约 285 KB，包含全部逻辑、样式与程序化绘制的美术资源——没有图片、音频文件，也没有构建步骤。

源码收录于 [Songhonglei/art-creativity](https://github.com/Songhonglei/art-creativity) 的 `city-rider/`，各项目相互独立。

## 本地运行

无需安装依赖或构建。克隆聚合仓库后进入游戏目录：

```bash
git clone https://github.com/Songhonglei/art-creativity.git
cd art-creativity/city-rider
python3 -m http.server 8080 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8080>。也可以直接双击 `index.html` 打开；推荐使用静态服务器，以便晒图分享等能力正常工作。

整个目录可以直接部署到任意静态站点服务。不需要后端、数据库或账号系统。

### 车与人

三辆公路车各有取向，能力条在车库里直接可见：

| 车 | 极速 | 特点 |
| --- | --- | --- |
| 破风 · AERO | 56 km/h | 气动碳架，极速最高，冲刺更快 |
| 爬坡 · CLIMB | 50 km/h | 轻量爬坡架，提速迅猛，体力更省 |
| 耐力 · ENDUR | 52 km/h | 舒适耐力架，操控稳健，均衡之选 |

骑手可切换男 / 女两种形体（肩宽、腰线、髋部与肌肉量不同，女性有盔下马尾），另有车架、骑行服、头盔各 6 色与 6 档肤色。所有外观实时反映在车库预览、骑行画面与晒图上。

### 玩法

- **体力与踏频**：加速消耗体力，松油门或刹车回体力；体力见底会被限速，得靠能量胶和水壶补。
- **检查点续时**：每进入新路段补一次时间，三档难度补的秒数不同——这是能否骑完全程的关键。
- **金币连击**：连续吃金币累积连击，单枚分值随连击提升（上限 ×10），每 5 连额外奖励。
- **六种道具**：能量胶（体力 +40）、咖啡（6 秒极速提升）、水壶（体力 +20 / 时间 +3s）、护盾（12 秒免疫一次碰撞）、磁铁（8 秒自动吸金币）、时光钟（时间 +6s）。
- **六类障碍**：锥桶、井盖、减速带、护栏，以及会变道的社会车辆与出租车。碰撞掉速、扣体力并打断连击。
- **三档难度**：休闲（80s / 检查点 +30s）、挑战（62s / +23s）、大师（50s / +18s），车流密度与体力消耗同步提升。
- **星级结算**：完赛按剩余时间给 1~3 星（>25s 三星，>10s 两星）；未完赛按里程给 0~1 星。每城独立保存最佳成绩。

### 三套电台

全部由 WebAudio 程序化合成，没有音频文件：城市流行（Funk 贝斯，106 BPM）、松弛 Lo-Fi（慵懒电钢，74 BPM）、电子疾驰（四踩鼓机，134 BPM）。选「随机轮播」每 30 秒自动换一套。风噪随车速变化，静音偏好跨局保存。

### 领奖台晒图

完赛或时间耗尽后生成 1080×1350 竖版海报：城市地标背景、领奖台、当前外观的骑手、成绩与星级，配一段随天气季节变化的文案和话题标签。支持保存图片、调用系统分享（设备支持时）、一键复制文案。每次打开都会换一版构图。

## 操作

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 加速 / 刹车 | `W` / `S` 或 `↑` / `↓` | 右侧上下按钮 |

## 实现要点

- **伪 3D 道路**：分段投影 + 曲率累积 + 坡道遮挡剔除，单帧只绘制视野内 64~110 段（全赛道 2766~4218 段）。
- **骑手**：双骨骼 IK 解算踩踏，背视为后侧 3/4 机位，侧视按远腿 / 车架 / 近腿分层遮挡。
- **美术全程序化**：44 座地标、6 种路灯、7 种行道树、9 种墙体、车辆与道具全部用 Canvas 路径绘制后缓存为离屏贴图。
- **渐变缓存**：骑手与车架的渐变按「配色 + 量化坐标」缓存，色标惰性构造，避免每帧重复创建。
- **资源生命周期**：换城淘汰上一城的地标与天际线缓存；音频节点在 `onended` 回收，噪声缓冲复用；粒子推进与渲染分离，暂停时不推进。

实测水位（1440×900，Chrome）：骑行单帧渲染约 2 ms，九城连续骑行离屏缓存峰值约 10.6 MB，JS 堆约 9.5 MB。

## 存档

最佳成绩、外观选择、难度、电台与静音偏好保存在当前浏览器的 `localStorage`。清理网站数据、换域名或换设备不会继承。
