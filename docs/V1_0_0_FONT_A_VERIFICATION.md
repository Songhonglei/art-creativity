## 实施结果

- 开局主标题、h1–h4、品牌主字、角色名、目标名采用已确认的「得意黑」A方案。字重400、字距`.025em`，不再给单个静态字体虚报多个字重，不额外倾斜或描边。
- 正文、按钮、设置项及气血/材料等功能读数保持原样。浏览器对照原H5，确认按钮、开局说明、强化所正文/数值的字体、字号、字重未变。
- 原字体子集缺少本版新用字，已补为958字形。当前源码静态字符覆盖检查无缺字，包括梧桐巡守、江畔司夜、申城守望、白玉兰礼装及精修。
- 文件119104字节，比原99444字节增加19660字节（约19.2KiB）。轮廓和字宽表与批准的A预览完全一致；仅修改内部字库名为`RangerActionTitle`以遵守保留名称，保留原作者OFL。
- H5与离线入口同步、添加包内字体预加载。没有新增外网字体请求或原生API。

[构建与字形散列](evidence/v1.0.0-font-a/build-manifest.json)记录源码、字体、H5、IIFE和ZIP的SHA256。[浏览器回执](evidence/v1.0.0-font-a/browser-results.json)记录实际样式、字体加载及错误检查。
