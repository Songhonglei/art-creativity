## 规则与数据

### 成长

有效调查8、街坊求助10、游荡制伏5、主目标制伏20、委托完成60。出战100%，待命50%；以事件唯一 ID 去重，不为空放、挂机、自伤、救援或休息给经验。升级阈值40/60/90/120/160/200/250/300/360，总1580。每次升级增加1点，9点总预算、单项最多5点。推荐只分剩余点，脱战免费重置和换特性。

- 守护：救援恢复基础30%，每点＋2个百分点，上限40%，不增加救援次数。
- 活力：主动冷却每点－0.6秒，最多－3；等级基础24/22/20秒，晴夜恢复速率1.15，实际不短于12秒。
- 专长：橘猫主动治疗每点＋2个百分点；柯基回体每点＋3；柴犬发现范围每点＋0.8米、识破增伤每点＋2个百分点。
- 橘猫治疗12%→20%，回春额外3个百分点；减伤3→9点。柯基回体44→58，回气额外＋2体力/秒。柴犬增伤12%→20%，识破特性额外4个百分点，发现范围8→12米。数值显示来自同一规则函数。

### 三宠技能

橘猫：C回血和短保护；Lv3溢出治疗转4秒护盾，上限8%最大气血，Lv8升至12%。非致命受伤后低于30%时自动恢复8%气血并短保护，45秒冷却，护主特性缩至38秒；Lv10自动保护额外恢复5%。护盾不叠层。

柯基：C回体；Lv3附加4秒减耗15%，Lv8减耗20%，Lv10基础6秒；节能特性额外2秒，最多8秒。低于20体力自动补24，45秒冷却。回气特性常驻恢复＋2/秒。覆盖普通攻击、重击、闪避、疾跑；不打断攻击和闪避，不控制敌人，不加治疗或伤害。

柴犬：探索中C生成避障地面足迹指向调查/目标/收缴处；Lv3同时标出发现范围内一处未取补给。战斗中自动选择可见有效锁定目标或最近威胁，下一次正常命中增伤；标记8/10/12秒，落空、隔墙、打其他目标不消耗。Lv10首击后留一次半额标记；探索调查后自动接续一次，保留原时长。探路特性足迹多4秒，识破特性增伤多4个百分点。没有目标不扣冷却，无需手动切模式、点怪或指定轻重击顺序。

### 救援、回营、存档

每轮一次共享救援：致命伤后0.7秒自动扶起，按守护恢复气血、2秒保护、清除连续击退。再次倒下显示底部恢复卡，明确攻击来源与实际伤害；按钮“回大排档”移至真实安全营地（-18,31.2），不重开委托。回营休息或完成委托进入下一轮才补救援；切宠、加点、换肤、脱战、刷新不能补次数、冷却或增益。

小工具客户端满足 9.46 版本条件且具备对应 API 时，优先使用原生 Storage JS API；未满足条件时兼容浏览器存储。启动先读取进度和设置，再创建引擎；读取失败不覆盖旧数据。原生写入按 key 串行，收到成功回执才显示已保存，较旧回执不覆盖较新状态。原生空槽可导入旧浏览器存档。原生路径只做 mock／浏览器注入验证，容器真机验收单列。

Schema v3 分宠保存成长/经验/属性/特性/皮肤，保留旧存档 key。旧共享训练1/2/3级一次迁移至三宠1/4/7级，补发点数、自动解锁对应皮肤、不重复扣资源。保存委托编号、调查、资源领取、主目标状态、游荡状态、英雄状态、天气、已结算事件、共享冷却/救援及剩余增益。事件结算及时保存，游戏中定期保存，暂停/切后台补检查点；暂停不推进计时。写入失败保留内存状态、准确提示、重试保存当前状态，不重复收益。

## 实现分层

- `pets.ts`：成长、属性、特性、皮肤目录与统一数值；`petNavigation.ts`：有界避障路线。
- `simulation.ts`：真实事件结算、能力/救援/回营、检查点；`persistence.ts`：schema验证与恢复。
- `creatures.ts`：真实低多边形皮肤；`engine.ts`：缓存、足迹/标记/护盾、宠物动作和输入。
- `PetContent.tsx`＋`PetPreview.tsx`：成长与真实模型预览；现有Hud/菜单接入，CSS处理手机与键盘。
- 验证逐项记录“通过／失败／未验证”，浏览器模拟不写成Android/iOS或小红书真机通过。
