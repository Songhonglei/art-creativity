## 性能与资源回收

[最终同一标签页重复采样](evidence/v1.0.0/performance-final.json)：Apple M1 Pro / ANGLE Metal，1024×768、流畅档，两版本均固定相同三处坐标与镜头，每轮60个RAF间隔，重复两轮；暂停simulation tick仅比较渲染。v0.9.5 p50为33.0/33.1ms、p95为42.2/41.7ms；v1.0.0为33.4/33.4ms、41.7/42.1ms。两轮p95相对变化约−1.2%/+1.0%，在建议10%范围内。原夜鹰模型14192→12034三角形、35→23调用、角色点光源2→0。场景分块加载/粒子仍会造成少量统计波动；这个桌面短采样不证明手机30fps或整局流畅。

[受控前的标签页采样](evidence/v1.0.0/performance-background-tab.json)出现约1秒RAF间隔，保留为异常记录；其新旧位于不同标签页，不能用来判断模型回归。改为同一新建标签页依次加载两版后得到上述结果，不删除或筛掉单轮慢帧。更早的[开发中采样](evidence/v1.0.0/performance-comparison.json)仅供历史参考。

[最终HUD与12次试衣开关](evidence/v1.0.0/hud-lifecycle-results.json)：先等场景分块稳定，连续三种皮肤预览、关闭12次；关闭后只有游戏canvas1个，游戏GPU几何221→221、纹理23→23。主动GC后的JS heap为62,532,044→63,974,656字节（约+1.38MiB），backing storage增加32字节。独立跨版本采样heap为约46.0→86.0MiB，未隔离浏览器进程/缓存，不能据此断言无内存回归；目前没有单次切换持续增加GPU资源的现象。长时与真机内存仍待测。

## 已修正的问题

- 双手重击超出左臂可达范围：共享握点约束到两臂可达交集，兵器同步。
- 长衣直方块、倒地穿地及负地形悬空：曲面分片、腿部跟随，地面约束相对真实地形，并排除兵器扫掠对全身高度的干扰。
- 初版角色调用过多：按肢体/材质合批，最高39调用；去除角色附加点光源，保留现有场景照明。
- 手机地图溢出、导航裁切、附近交互隐藏重击：重排响应式布局，四动作持续可用。
- 试衣竖滑抢滚动、保存警告被标题盖住、Esc在SELECT中失效：修正方向判定/层级/键盘事件次序。
- WebGL丢失时未保存提醒丢失或重叠：收敛到单一恢复层，保存与重新加载焦点可达。
- 完成提示“第N夜”及剩余HUD小字号修正；加入旧WebView位置与Flex gap回退。
