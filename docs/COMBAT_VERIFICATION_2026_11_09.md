# 打击、闪避与血条验证记录

## 本次行为

三种武器各有轻重击动作：战术棍侧劈／双手蓄力劈砸，伸缩棍快刺连击／转体横扫，战术伞闭伞刺击／开伞扫击。动作由准备、接触、收势三个阶段组成，手部跟随武器握点，限制到手臂可达范围。

| 武器 | 轻击接触 | 重击接触 | 重击动作时长 |
| --- | --- | --- | --- |
| 碳纤维战术棍 | 0.14 秒 | 0.36 秒 | 1.00 秒 |
| 钛合金伸缩棍 | 0.09 秒 | 0.24 秒 | 0.76 秒 |
| 霓虹长柄战术伞 | 0.12 秒 | 0.32 秒 | 0.94 秒 |

伤害、飘字、受击反馈和命中音效在接触时触发。挥中时重新检查距离、朝向和墙体；闪避、实际受伤会取消未结算的攻击。暂停冻结动作，重开夜巡清除未完成攻击。重击、普通命中和格挡有不同反馈，稳定镜头设置仍可关闭镜头震动。

闪避保持站姿，按可用路径与概率选择左后／右后方向。开阔处移动约 3.25 米、持续 0.36 秒；路径受阻时缩短距离，两侧都无空间时不扣体力、不获得原地无敌。原有宠物保护不会被闪避缩短。

「怪物血条」默认开启，设置统一控制主目标与三个游荡目标的头顶血条、战斗面板血量及百分比。关闭后保留目标动作提示。旧设置缺少该字段时按开启处理，关闭选择随本机设置保存。

触屏动作、奶茶、宠物技能和锁定按钮按下即响应，支持摇杆保持按住时由另一根手指出招；松手产生的点击不会重复触发，键盘激活仍可使用。

## 验证结果

- `npm test`：97 项通过，其中新增 15 项招式与闪避回归；原战斗测试按新的接触时间等待结算，保留伤害、破防、奖励及冷却断言。
- `npm run build`：TypeScript 与 Web 构建通过，原有的大分块体积提示仍存在。
- `bash scripts/build-tool.sh`：经典 IIFE 离线 H5 与小红书 ZIP 构建、目录审计通过。
- Python 最终 ZIP 审计通过，共 17 个文件，压缩包内容与 `dist-tool` 逐字节一致。
- ZIP 大小 2,266,335 字节，约 2.16 MiB；低于 10 MiB 上限，高于 2 MiB 建议值。
- SHA-256：`6fed175da8afe25e2d2c9af1f8a3f714b29e0e87a5267c89378b4219f2121384`。

浏览器检查使用 macOS Chromium，包含 390×844 手机视口：

- 重击先进入准备动作，接触时触发命中；实测出现「重击 137」，目标血量由 150 变为 13。
- 检查六套武器接触姿态；战术伞只有重击展开伞面，侧视截图确认战术棍抬手蓄力和开伞姿态。
- 血条初始开启；关闭后头顶血条、战斗面板血量与百分比全部隐藏，动作提示保留；刷新后仍关闭，再开启恢复展示。
- 浏览器原生多点触摸注入：左手保持摇杆移动，第二根手指按下重击立即响应；松手后动作调用仍为一次。再次保持摇杆时按闪避，可以取消重击并撤步。
- 键盘 Space 激活聚焦的攻击按钮只触发一次攻击。
- 最终离线 IIFE 在禁止外部网络、内联脚本与 Worker 的 CSP 下验证重击、后撤、血条开关；最终重打包后又验证第二根手指按下即响应。未捕获脚本错误，请求均为包内资源。
