# 全局静音修复记录

## 排查结论

音频包含持续运行的风声、城市低频振荡器和战斗底音，全部经过主音量节点。旧版关闭声音仅用 `setTargetAtTime` 渐弱主音量，保持输出连接；静音时的 `unlock()` 仍可能创建／恢复音频上下文。

Chromium 实测旧版在关闭约 200ms 后仍有残响，峰值约 0.01858；约 1.2 秒后采样为 0。本次未复现长期不消失的嗡声，不能认定短暂残响就是用户所述持续嗡声的唯一原因。

## 修复

- 关闭声音或主音量为 0：取消主音量自动化，立即设置 0 并断开通往扬声器的主输出。
- 停止音乐调度及已排队的短音效。持续环境声源可供恢复复用，但静音期间无扬声器输出。
- 静音时 `unlock()` 不创建、恢复音频上下文；出招、切换声景、靠近环境声源不能重新打开输出。
- 开启声音时只连接一次输出、保留所选声景；初始化异常和销毁均断开输出、关闭上下文。
- 顶部声音按钮、设置开关与音量滑块直接应用音频状态，再保存界面设置。

## 验证

浏览器将分析器接在主音量之后采样，并让分析器连接输出以持续处理音频图。四套声景分别叠加暴雨、战斗底音、车辆／冷柜环境音、延后胜利音效，再关闭声音或将音量归零：

| 声景 | 开启峰值 | 关闭后峰值 | 恢复后峰值 | 音量归零后峰值 |
| --- | --- | --- | --- | --- |
| 电子夜脉 | 0.04845 | 0 | 0.06632 | 0 |
| 梧桐爵士 | 0.06309 | 0 | 0.08771 | 0 |
| 江畔氛围 | 0.06816 | 0 | 0.07159 | 0 |
| 老城电台 | 0.07488 | 0 | 0.09412 | 0 |

关闭／归零后的采样等待约 180ms，以排除分析器中上一段音频的缓存。数值为本次测试信号峰值，不是设备音量或分贝。

- 静音刷新后不创建音频上下文；静音出招、天气／城市变化及切换声景不重连输出。
