# 沪上游侠 v0.9.0

上海都市背景的第三人称 3D 夜巡游戏。包含七类城市祸害、现代侠客与宠物、简化强化、天气和浏览器本地存档。

核心城区之外采用固定种子的动态街区：走近时生成地形、道路、建筑和碰撞，远离后回收；小地图、区域名、宠物寻路与回营流程会同步适配。同一街区的布局在重进后保持不变。

## 城市风貌与装备

- 五类城市风貌拥有不同轮廓与街道构件：玻璃退台摩天楼、带裙楼和设备屋顶的写字楼、砖瓦石库门老弄堂、阳台店面与梧桐街道、红砖柱廊与钟塔大学城。
- 外滩、东方明珠、上海中心、环球金融中心、金茂大厦、外白渡桥等地标保留在手工核心城区；另增江湾斜拉步行桥、梧桐口袋公园和动态水纹池塘。
- 主要路线附近可遇到 24 小时便利店、黄色出租车与醉酒少年。角色靠近时，门铃、短暂发动机声／鸣笛、瓶碰、虫鸣与流水声按随机间隔轻声出现；江边偶有短船笛，离开后收掉尾音。没有常驻冷柜、车辆嗡声或城市噪声。
- 城市兵器包括碳纤维战术棍、钛合金伸缩棍和霓虹长柄战术伞；战术伞在侠义三级解锁，攻击时展开伞面。
- 侠客衣橱提供夜鹰巡衣、白玉兰礼装、霓虹行者三套完整造型，可随时切换并与任意兵器、宠物搭配。

## 项目结构

- `src/App.tsx`：页面状态、设置保存与引擎生命周期。
- `src/game/engine.ts`：输入、镜头、渲染与游戏规则的连接。
- `src/game/camera.ts`：球面环绕、多点手势、锁定优先级与三维镜头避障。
- `src/game/simulation.ts`：战斗、任务、宠物能力与救援；`pets.ts`：统一成长数值、特性、皮肤目录；`petNavigation.ts`：有界避障引路。
- `src/game/persistence.ts`、`storage.ts`：检查点校验、原生／浏览器存储适配、旧档迁移与异步保存状态。
- `src/game/world.ts`、`streaming.ts`：核心城区与动态街区。
- `src/game/audio.ts`、`soundscapes.ts`、`ambience.ts`：四套清爽音乐、有限时长音效与按距离／天气调度的环境声。
- `src/components/`：状态界面、地图和菜单。

项目位于 [Songhonglei/art-creativity](https://github.com/Songhonglei/art-creativity/tree/main/shanghai-ranger) 的 `shanghai-ranger/`，运行命令均在该目录执行。

## 开始运行

需要 Node.js 22.16 或更高版本。

```sh
npm ci
npm run dev
```

## 操作

- WASD／方向键移动，Shift 疾跑，鼠标拖动可围绕角色水平 360° 环顾和有限俯仰；滚轮缩放，V 或「归位」按钮恢复身后视角。
- J／左键轻点攻击，K／右键轻点重击，空格闪避，E 交互，R 喝奶茶。
- M 地图，F 强化，G 手册，Q 锁定目标，C 释放宠物主动技，P 打开宠物成长与皮肤。
- 手机竖屏、横屏和平板均可左手摇杆移动、右手拖动空白场景环顾；两根场景手指张合缩放，也可同时保持左手移动。摇杆和出招按钮的手指不参与镜头手势。
- 拖动不触发攻击；双指缩放结束后可用剩下一根手指继续环顾。取消触摸、失焦、切后台、转屏和打开菜单均清理输入。
- 锁定时手动环顾优先，松手 1.6 秒后平滑跟回目标；「归位」立即恢复锁定方向。镜头根据建筑高度、地标塔柱和地面／桥面收缩，离开遮挡后平滑拉回。

普通浏览器存档保存在 localStorage；小红书客户端满足 9.46 版本条件且提供对应 API 时，优先使用小工具本地缓存。启动先读档，原生读取失败时停止加载，避免覆盖旧存档；原生空槽可导入旧浏览器存档。两条路径都不会跨设备同步，清除对应数据会删除存档。写入失败时会保留当前游戏状态并提示未保存，可在恢复存储权限或腾出空间后重试；重试不会重复结算奖励。设置保存失败也会提示，刷新前请确认保存成功。旧版 schema version 1／2 存档会一次迁移为 version 3，保留材料、现金和装备；旧宠物共享训练 1／2／3 级对应三宠各自 Lv1／4／7，补发属性点和对应皮肤解锁。

## 夜巡规则与成长

- 每夜先在当前城区调查三处线索，目标才会现身；攻击同时检查距离、朝向扇形和墙体视线。
- 主委托之外始终保留三个街区游荡目标槽位。目标在附近可见，靠近后才追击；制伏后立即获得小额现金、每两次额外获得零件，延时自动补位，远离旧区域也会安全重定位。游荡奖励不会增加主委托完成数。
- 后续委托在老弄堂、写字楼、大学城、摩天楼和梧桐区之间轮换，地图金色虚线始终指向当前有效目标。
- 野猫与野狗灵活扑击，无牌电驴与鬼火少年冲撞后收势较久，地痞与强盗会格挡、需要用重击破防；每四夜出现高额精英委托。
- 街坊求助、奶茶和零件堆提供额外补给。脱战不会瞬间回满目标气血，也不能靠反复拉扯无成本消耗。
- 三宠分别通过调查、求助、制伏与完成委托获得经验，独立 Lv1–10；出战完整经验，待命获得一半。每级一属性点，Lv5 选择特性，脱战可推荐分配或免费重置。成长不消耗零件或现金。
- 橘猫回血护盾与低血护主；柯基回体、常驻恢复与行动减耗；柴犬自动地面引路／补给发现、战斗标记弱点。战斗中仍只用 C／一个宠物按钮，不要求特殊按键顺序。
- 每宠原皮肤＋Lv4／7／10 三款专属外观，共 12 套真实低多边形模型；原皮肤保留、免费自动解锁、玩家自行穿戴，4级配饰、7级完整套装、10级精装强化，逐级保留主要服装构件；柴犬与柯基分别建模。宠物页可旋转预览，皮肤不改变属性。
- 每轮有一次公共自动救援；用完后再倒下可从底部恢复卡回真实大排档，保留委托、调查、目标气血和收益。切宠、换肤、加点、刷新不补救援或技能；回营休息或开始下一轮才补救援。
- 兵器精修仍消耗零件与现金，加成对全部城市兵器有效。成长、穿戴与本轮检查点自动存档；原生路径按回执更新保存状态，失败可重试，不重复发奖。
- 流畅、均衡、高画质会实际调整像素比、阴影、植被、雨线和动态街区加载半径。
- 晴夜远离声源时只播放音乐；暴雨间歇出现一小阵雨声，雾霾偶有轻风。环境音共享 4–7 秒安静间隔，靠近才触发并随距离降低音量，战斗时再次压低；近处猫狗叫声也有冷却。菜单内只试听音乐，环境声暂停。
- 设置中可在电子夜脉、梧桐爵士、江畔氛围、老城电台四套本地合成声景之间切换：电子琶音、爵士摇摆和弦、水岸长音和复古旋律。设置页内可直接试听，选择会随其他设置一起保存；静音时只保存选择。关闭声音或音量归零会立即切断全部音频输出；静音下的移动、出招和切换声景不会重新启动音频。
- 三把武器分别使用劈砸、快刺／横扫、闭伞刺击／开伞扫击动作；重击有更明显的蓄力与收势，伤害在接触时结算。挥中时重新检查距离、朝向与墙体，闪避或受伤可中断蓄力。命中、重击、格挡使用不同的挥痕、冲击圈、飘字与音效。
- 闪避保持站姿，按概率与可用空间选择左后或右后方，后撤距离约 3.25 米；空间有限时缩短距离，两侧堵住时不扣体力，也不获得原地无敌。
- 设置中的「怪物血条」默认开启，统一控制附近目标的头顶血条和战斗面板血量；关闭后保留目标动作提示，选择随设置保存在本机。
- 核心黄浦江面与动态街区水面使用时间驱动的顶点波动、流动高光和沿岸水纹；桥梁附近会贴合桥面高度行走。

## 测试与构建

```sh
npm test
npm run build
npm run preview
```

普通构建文件位于 `dist`。`npm test` 包含游戏规则、招式与闪避、镜头手势、音频、间歇环境声、独立宠物成长与模型、检查点恢复、存档失败及原生缓存回执测试。当前182项测试及最新美术验收见 [宠物模型与等级皮肤修订](docs/PET_VISUAL_REVISION_2026_11_10.md)；[初版功能验收](docs/V0_9_0_VERIFICATION.md)保留作历史记录。

生成小红书小工具离线 H5 ZIP（自动查找 `webapp-building-pro` 内置 builder，也可用 `MINITOOL_BUILDER_DIR` 指定）：

```sh
bash scripts/build-tool.sh
```

输出为 `output/沪上游侠-小红书小工具.zip`；同版 H5 位于 `dist-tool/index.html`。入口、字体、脚本和样式均随包提供。普通浏览器检查不能代替小红书容器验收，上传后还需分别验证平台模拟器、Android 与 iOS 真机。

改名保留原存档与设置的内部键，已有浏览器进度仍可读取。
