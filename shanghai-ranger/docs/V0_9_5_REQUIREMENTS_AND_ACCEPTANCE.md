# v0.9.5 死亡恢复：需求、方案与验收

日期：2026-11-10。基线 v0.9.0，目标 v0.9.5。状态：已实现，本地验收通过；结果与边界见 [验收报告](V0_9_5_VERIFICATION.md)，平台与真机仍未验证。

## 目标与范围

减少失败后的赶路、重复调查和困惑，保留完整战斗的挑战。用户已确定主角倒地反馈 1.5 秒，授权本次完整升级。宠物不改：三宠能力、模型、成长、冷却、0.7 秒公共救援、回血比例和 2 秒救援保护保持现有规则。工作区已有宠物外观修订，不覆盖其改动。

本版交付就近再战、阶段保留、针对性提示、条件强化入口、死亡与复活视觉/声音、存档兼容、H5/离线小工具构建。回大排档保留地图入口，不作为战败卡常驻次按钮。不增加扣钱、掉落、体力等待、复活次数限制或广告。先前讨论的连败 15% 减伤为可选方向，本版不启用；先验证基础恢复体验。

## 用户流程

1. 首次致命伤仍走原宠物救援，不进入战败流程。
2. 救援耗尽后再次致命受伤：立即记录死因、冻结敌人/天气/技能计时、清除输入，开始 1.5 秒倒地反馈。期间不能通过菜单或操作绕过恢复流程。
3. 1.5 秒结束显示恢复卡，默认聚焦“再试一次”。卡片说明调查和物品保留，显示一条根据致命攻击来源选择的战斗建议。伤害数字放可展开详情。
4. 只有当前材料可提升侠义或精修兵器时，显示“去强化”。强化页保持战败暂停，关闭回恢复卡；底部“再试一次”直达，不先回营。打开/关闭菜单不重复播放倒地。
5. 选择再试一次：约 0.3 秒暗色转场内完成恢复和位置切换，再放开移动/攻击。主角满血、满体力、奶茶至少 5 杯（原先超过 5 不减少）；清除攻击、闪避、击退、锁定和连击残留。
6. 再战视为省去现有回营休息与返程，补充公共救援；宠物主动/自动技能冷却及已有增益不刷新，不以复活给经验。保护期 2 秒，时间只在实际游戏推进时消耗。
7. 约 0.6 秒起身表现与移动并行，不能变成额外操作锁。保护提示与保护剩余时间对应，结束即消失。玩家进入战区重新挑战。

## 阶段与资源规则

| 内容 | 再战处理 |
| --- | --- |
| 永久成长、装备、现金、零件、宠物养成 | 原样保留，不扣除、不复制 |
| 已取得线索和委托阶段 | 保留；调查中不会提前揭示主目标 |
| 已领取资源、已完成街坊事件、经验去重集合 | 保留；复活/刷新不重复结算 |
| 未制伏主目标 | 恢复满血，回委托位置，重置暴怒、冲撞、连击与攻击计时 |
| 已制伏待收缴 | 保留零血和待收缴阶段；只发一次奖励 |
| 已完成委托 | 保留完成和收益，不回退、不跳到下一轮 |
| 游荡敌人 | 保留生命/奖励/刷新身份，重置攻击动作；选择安全恢复点，沿用原刷新机制 |
| 天气、夜巡时间 | 再战不额外推进天气、不清零 |

恢复锚点：参与主目标战斗时使用目标所属战区，否则使用死亡附近；旧存档没有锚点时按当前阶段/位置推导。先加载锚点周围地图碰撞，再在 18–36 米内搜索可站立、远离主目标和存活游荡敌人的位置；保持同一岸，避开水域、建筑、障碍和营地外被围困的位置。找不到时回真实安全营地，并明确提示；不能进入墙体、河里或死循环。新刷出的游荡敌人也不能在复活保护期贴身出现。

## 表现设计

方向：沿用上海夜巡的藏青夜色、黄铜和湖绿，呈现“暂时倒下，重新站稳”。保留现有本地中文字体。DFII：影响4、贴合5、可实现5、性能4、维护风险3，总分15。

### 死亡 1.5 秒

- 0–0.35 秒：身体逐渐侧倒，腿臂收势，武器随身体放低；不瞬间横转成悬空木板。停止普通低血闪动、攻击拖影和危险圈。
- 0–0.6 秒：场景平滑降低饱和度并压暗边缘，仍看得清角色和街道。小幅镜头调整不改变玩家观察方向，不用剧烈震屏。
- 0.35–1.5 秒：身体停稳，显示简短“暂时倒下了”；不显示抢眼倒计时、不全屏红闪、不责备玩家。
- 致命倒地只播放一次低声落地/收束音；宠物救援音与战败音分开。静音、音量 0 不创建新声音。
- 1.5 秒恢复卡从底部轻入场，场景继续停留在倒地状态。

### 再战与复活

- 点击立即锁住重复提交，暗色遮罩约 0.15 秒进入、0.15 秒退出，位置和镜头切换在遮罩最暗时发生；不闪白。
- 镜头归位到主角身后，旧摇杆/按键/指针状态清空。宠物只随主角转移到旁边安全位置，能力与模型不改。
- 主角由低姿态起身，约 0.6 秒恢复直立，可立即走动；脚边单层湖绿环短暂展开并淡出，使用有界复用几何，不创建粒子风暴。
- 两秒内显示“已恢复 · 短暂保护”，保护结束立即移除。普通受击无敌不冒充复活保护。
- 复活音为短而轻的上行音，服从静音/音量。不会反复播胜利音或刷新环境声。
- 减少动态模式/系统减少动态：保持相同时间与规则，省略翻转、扩散、位移、镜头特效，使用稳定姿态和简单淡入淡出。

## 数据与实现

- 保留原存档 key 与 schema v3，用可选恢复锚点兼容 v0.9.0；无效位置验证后回退，旧永久成长不重置。
- 战败及时存档；再战只执行一次并保存恢复后的状态；失败提示与重试保存继续有效。刷新死亡存档进入恢复卡流程，刷新恢复后存档不补血/救援/奖励。
- UI 1.5 秒由独立前台计时控制，不依赖已冻结的战斗时钟；切后台不抢跑视觉过程。转场和计时卸载清理。
- 规则集中在 simulation/recovery 模块，视觉动画使用独立表现时钟，普通暂停不推进战斗。渲染每帧不触发 React 全量更新。
- 版本同步 package/lock、H5入口、离线入口、README及版本产物；不改写历史验收结论。构建后生成独立 v0.9.5 ZIP，保留旧包。
- 不包含外网部署、商店上传或 Git 推送；本次本地实现及可交付包。
