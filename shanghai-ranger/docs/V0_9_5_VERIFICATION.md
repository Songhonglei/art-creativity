# v0.9.5 死亡恢复验收

日期：2026-11-10。结果：**本地实现、自动化、浏览器及生产包验收通过**。基线 v0.9.0；未部署线上、未上传小红书平台，未做 Android/iOS 真机验收。

## 交付行为

- 原宠物自动救援规则保留。救援耗尽后倒下，战斗立即冻结，侧倒和夜色淡出共 1.5 秒，再显示恢复卡。
- 主动作“再试一次”；有足够材料时才显示“去强化”。强化后直接再战，关闭强化页不重复倒地。回营仍在地图入口。
- 约 0.3 秒暗色转场，就近恢复满血满体、奶茶至少5杯、公共救援可用；约0.6秒起身不锁移动，提供2秒保护与准确提示。没有额外复活费用。
- 调查、领取记录、收益和养成保留；存活主目标满血、重置暴怒和招式；待收缴/完成阶段保留。技能冷却、已有宠物增益不刷新，不因复活给经验。
- 落点搜索避开建筑、圆形障碍、水域及敌人，保持同岸；无安全落点则回真实营地并说明。旧存档继续使用同一个 key 和 schema v3。
- 死亡用渐进侧倒、低饱和夜色和低声收束；复活用暗色转场、起身、单层湖绿环和短音。无闪白和强震屏，游戏/系统减少动态均有降级。

## 验证结果

| 要点 | 结果与证据 |
| --- | --- |
| D01 宠物救援 | 原0.7秒、恢复比例、次数、2秒保护回归通过；宠物能力/成长/模型未修改。本版只同步了宠物页对死亡后去向的说明。 |
| D02 倒地时间和冻结 | Playwright前台可控时钟测得 **1500ms**；1400ms无卡，1500ms后有卡。时间、天气、宠物冷却冻结，M不能绕过。此为逻辑时序验证，不是硬件渲染延迟基准。 |
| D03 倒地表现 | 浏览器中身体侧倒角度−1.42，截图核对侧倒、压暗、恢复卡。死亡期间停止危险圈和攻击残留；动效依靠表现时钟，战斗不推进。 |
| D04 死因与建议 | 车辆/扑击/格挡/精英/未知来源建议覆盖，详情可展开查看实际伤害。 |
| U01/U02 操作 | 无材料时只有再试一次；有材料时出现强化；完成强化后直接重试；关闭菜单立即回恢复卡。修复了死亡遮罩挡住强化页的问题。 |
| R01 状态/重复提交 | 满血满体、奶茶补给、动作清理通过；浏览器连续调用按钮仅产生一次revive事件，恢复后可移动。 |

```sh
npm test
npm run build
bash scripts/build-tool.sh "$(pwd)/output/沪上游侠-v0.9.5-小红书小工具.zip"
# 开发服务5185已启动时（需要Python Playwright）：
python3 scripts/verify-recovery.py
# dist与dist-tool分别由本机5187/5186静态服务提供时：
python3 scripts/verify-recovery-builds.py
```

浏览器使用隔离上下文和人工构造的测试存档，不接触用户真实存档。首次软件渲染/截图会阻塞帧与计时采样，因此将受控前台时钟验证与截图走查分开；不把模拟时钟的1500ms宣传为所有设备上的实测延迟。后台切换计时有实现保护，真实操作系统后台/前台切换未单独做真机专项验证。
