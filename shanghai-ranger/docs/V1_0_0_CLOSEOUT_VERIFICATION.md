旧字体A离线包与本轮IIFE，390×844、DPR1、相同10级女性/柴犬存档，手动档位且关闭自动调节。镜头yaw=-0.07、pitch=0.2、distance=8.2；核心(0,20)、营地(-18,31.2)、外城(240,240)。欢迎面板保持模拟暂停，避免敌人和时间漂移；等待实际可见主角绘制后读renderer.info。新版仅在采样前用QA排空街区任务，**排空耗时不用于帧性能结论**。这是固定画面负担比较，不是FPS测试；高档数据包含可能的阴影额外pass。
